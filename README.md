# EnovelCms 小说管理系统

## 一、项目介绍

EnovelCms 是一款原生 PHP 小说建站管理系统，基于 PHP8.0 + MySQL5.7 开发，无复杂前端框架，占用服务器资源低，内置完整前台阅读、多端后台、全自动采集、会员充值、签到、自定义榜单、多语言、广告管理全查功能，适合搭建网文阅读站点。

## 二、环境要求

1. PHP 版本 ≥ 8.0，需开启扩展：cURL、mbstring、fileinfo、zip
2. MySQL / MariaDB ≥ 5.7
3. 服务器支持 Apache / Nginx / IIS
4. 目录读写权限要求：`data/`、`assets/uploads/`

## 三、安装步骤

1. 将源码完整上传至网站根目录；
2. 复制 `includes/config.example.php`，重命名为 `includes/config.php`，填入数据库地址、账号、密码；
3. 给 `data/`、`assets/uploads/` 目录设置 755/777 读写权限；
4. 浏览器访问 `域名/install/install.php`，跟随安装向导完成数据库导入；
5. 安装完成后建议删除 `install` 文件夹，提升站点安全；
6. 后台访问地址：`域名/admin/`，使用安装时设置账号密码登录。

## 四、整体目录结构

- `admin/` — 后台全部管理页面
- `api/` — 前台异步接口、支付回调、采集发布接口
- `assets/` — 前端静态资源：css/js/字体/上传图片
- `data/` — 缓存、采集临时文件、日志、封面存储（需可写）
- `includes/` — 系统核心类、数据库、函数、配置、语言包
- `install/` — 数据库安装、升级脚本
- `templates/` — 前台多主题模板文件夹
- `index.php` — 网站前台入口文件
- `README.txt` — 项目说明文档
- `LICENSE` — MIT 开源协议文件
- `升级教程.txt`
- `安装教程.txt`
- `采集规则.json` — 示例采集规则模板

## 五、后台功能清单

### 基础控制台
展示小说、用户、章节、榜单统计数据；显示站点总阅读、收藏、今日签到数据；版本更新检测、管理员密码修改、官方公告。

### 系统设置
- 网站名称、Logo、统计代码
- 注册模式（普通/邮箱验证）
- 书库每页显示数量
- 金币签到奖励规则
- VIP 价格（人民币/金币）
- SMTP 邮件服务器配置

### 小说管理
- 小说增删改查，支持封面上传
- 分类管理（排序/映射）
- 分卷管理（多卷结构）
- 章节管理（支持 HTML 内容，自动统计字数，分页显示）

### 采集规则管理
- 可视化配置采集规则（列表页、详情页、章节页、内容页）
- 支持分页、分卷、分类映射、封面下载
- 支持单篇/批量采集，断点续采
- 支持规则导出/导入（JSON 格式）
- 适配火车头/蓝天采集器发布接口

### 广告管理
- 多位置广告（首页轮播、侧边栏、详情页、阅读页等）
- 支持 HTML 代码，可投放任何广告联盟代码
- 关键词自动链接替换（章节内容生效）

### 用户与会员
- 用户管理（金币、VIP 等级、到期时间）
- 每日签到（连续签到奖励递增）
- 金币兑换 VIP
- 支付集成（易支付，支持支付宝/微信）

### Diy 自定义榜单
- 可视化配置缓存榜单（首页/排行榜等）
- 支持按分类、状态、字数、时间范围筛选
- 排序方式：点击、收藏、字数、最新、随机、自定义ID顺序

### SEO 设置
- 各页面独立 Title / Keywords / Description
- 支持变量替换：`{novel_title}`、`{author}`、`{category_name}`、`{chapter_title}` 等

### 主题管理
- 支持上传/切换/删除主题
- 主题包为 ZIP 格式，内含 `template.xml` 配置文件

### 其他
- 语言管理（支持多语言包上传/切换）
- 支付订单记录
- 签到日志
- 伪静态规则生成（Apache/Nginx/IIS）
- 系统更新检测
